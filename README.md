# 상승 삼각형 스캐너

S&P 500과 내 관심종목(약 680종목) 가운데 **상승 삼각형(Ascending Triangle)을 형성 중이고 아직 돌파 전**인 종목을 찾아 디스코드로 보냅니다. 매일 미국 장 마감 후 1회 실행됩니다.

## 알림 조건 (모두 충족해야 알림)

| 구분 | 조건 |
|---|---|
| ① 수평 저항선 | 최근 고점 3개 이상이 가장 높은 고점 대비 1.5% 안에 모임 |
| ② 높아지는 저점 | 패턴 시작 이후 저점 2개 이상이 차례로 1% 이상씩 높아짐 |
| ③ 패턴 기간 | 첫 저항선 고점부터 오늘까지 15~60거래일 |
| ④ 수렴 | 최근 10일 변동폭이 초반 깊이(저항선 − 첫 저점)의 50% 이하 |
| ⑤ 돌파 전 | 현재가가 저항선 아래 0~3% 이내 |
| ⑥ 선행 추세 | 주가 > 200일선, 50일선 > 200일선 |
| ⑦ 거래량 감소 | 패턴 기간 평균 거래량 < 패턴 직전 50일 평균 |
| ⑧ 상대강도 | 최근 3개월·6개월 수익률이 모두 SPY보다 높음 |
| 기본 필터 | 주가 $5 이상, 50일 평균 거래대금 $500만 이상 |

고점·저점은 "앞뒤 3거래일보다 높은(낮은) 날"로 자동 판별합니다. 그래서 가장 최근 3일 안의 고점·저점은 아직 패턴 판단에 쓰이지 않습니다.

## 디스코드 표 보는 법

| 열 | 의미 |
|---|---|
| RESIST | 저항선 가격 (돌파 기준가) |
| LAST | 현재가 (마감 후 실행이라 종가) |
| GAP% | 저항선까지 남은 거리. 작을수록 돌파 임박. 이 순서로 정렬 |
| HI | 저항선에 닿은 고점 개수 |
| LO | 높아진 저점 개수 |
| DAYS | 패턴 기간(거래일) |
| VOL | 패턴 기간 거래량 ÷ 이전 50일 평균. 낮을수록 매도 물량이 말랐다는 뜻 |

같은 종목·같은 저항선은 15일 안에 다시 알리지 않습니다. 저항선이 바뀌면(1.5% 이상 차이) 새 패턴으로 보고 다시 알립니다.

## 실행 시각

평일 한국 시각 **06:35** (미국 장 마감 후 확정 일봉 기준). GitHub 특성상 5~30분 늦을 수 있습니다.

## 설치 (새 저장소)

1. **디스코드**: 새 채널 생성 → 채널 설정 → 연동 → 웹후크 → 새 웹후크 → URL 복사
2. **GitHub**: New repository → 이름 입력 (예: `triangle-scanner`) → Public → 생성
3. **uploading an existing file** → `triangle.py`, `watchlist.txt`, `requirements.txt`, `README.md` 업로드 → 커밋
4. **Add file → Create new file** → 이름에 `.github/workflows/main.yml` 입력 → zip 안의 `main.yml` 내용 붙여넣기 → 커밋
5. **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `DISCORD_WEBHOOK_URL`
   - Secret: 1번에서 복사한 새 채널의 URL
6. **Actions → Ascending Triangle Scanner → Run workflow**로 테스트

## 설정 바꾸기 (`triangle.py` 맨 위)

| 항목 | 현재값 | 의미 |
|---|---|---|
| `RES_TOL_PCT` | 1.5 | 저항선 고점 허용 범위(%) |
| `MIN_TOUCHES` | 3 | 저항선 고점 최소 개수 |
| `MIN_HIGHER_LOWS` | 2 | 높아지는 저점 최소 개수 |
| `LOW_STEP_PCT` | 1.0 | 저점 간 최소 상승폭(%) |
| `MIN_DAYS` / `MAX_DAYS` | 15 / 60 | 패턴 기간(거래일) |
| `SQUEEZE_RATIO` | 0.5 | 수렴 판정 비율 |
| `NEAR_RES_PCT` | 3.0 | 저항선까지 최대 거리(%) |
| `REQUIRE_TREND` / `REQUIRE_VOL_DRY` / `REQUIRE_RS` | 1 / 1 / 1 | 보강 조건 ⑥⑦⑧ (0이면 해제) |
| `PIVOT_K` | 3 | 고점·저점 판별 기준 일수 |
| `REALERT_DAYS` | 15 | 같은 패턴 재알림 금지 기간(일) |

관심종목은 `watchlist.txt`를 고치면 됩니다. 이평선 스캐너와는 별도 파일이라, 양쪽 목록을 같게 유지하려면 둘 다 고쳐야 합니다.

## 알아둘 점

- 차트 패턴 자동 인식은 사람 눈보다 엉성합니다. 첫 1~2주는 알림 온 종목을 차트로 직접 확인하면서 위 숫자를 조정하세요.
- 최근 상장주는 약 260거래일 이상의 시세가 있어야 판별합니다.
- 시세는 야후 파이낸스 무료 데이터이고, 야후에 없는 티커는 조용히 빠집니다.
